# Security policy

Thinpost is pre-1.0. Only the latest release and the `main` branch receive
security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately, not in public issues or
pull requests:

- Use GitHub's private vulnerability reporting: the **Report a vulnerability**
  button on this repository's **Security** tab.
- Or email [oss@zyno.io](mailto:oss@zyno.io).

Include the affected version or commit, a minimal reproduction and the impact
you expect. Do not include credentials, private keys, bearer tokens or
details that would give access to a live deployment.

We aim to acknowledge reports within a few business days and will coordinate
disclosure with you.
